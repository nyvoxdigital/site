# Cinematic Exhibition Portfolio

Immersive cinematic portfolio built with Next.js 15, React 19, TypeScript, GSAP, Lenis, Framer Motion, and React Three Fiber.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
```

The project is ready to import into Vercel as a Next.js application.
